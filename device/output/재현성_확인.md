# 재현성 확인

## 1. 같은 폴더에서 2회 연속 실행

`device/` 안에서 `node generate.js`를 두 번 연속 실행하고, 매 실행 직후 `output/site-data.json`,
`output/candidates.json`을 별도 위치에 복사해 `diff`로 비교함.

- `site-data.json`: **동일** (diff 결과 없음)
- `candidates.json`: **동일** (diff 결과 없음)

## 2. 새 임시 폴더에 복사해 README대로 실행

`device/` 폴더 전체를 스크래치 임시 폴더(`.../scratchpad/device_fresh_test`)로 복사한 뒤,
기존 `output/site-data.json`, `output/candidates.json`을 삭제하고(진짜 "처음 실행" 상태로 만듦)
README 3단계 그대로 `node generate.js`만 실행함.

- 추가 설치·설정 없이 바로 실행됨 (Node.js 외 의존성 없음 확인)
- 새 폴더에서 나온 `site-data.json`, `candidates.json`을 원본 `device/output/`의 결과와 diff
- 결과: **바이트 단위로 완전히 동일**

## 결론

`generate.js`는 무작위 값·현재 시각·외부 호출을 쓰지 않고 `input/`의 세 JSON 파일만으로 계산하므로,
같은 입력이면 실행 위치·횟수와 무관하게 항상 같은 출력을 낸다. (BRA-C09 통과 근거)
